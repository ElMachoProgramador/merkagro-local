Datos guardados en tu computador

Los cambios se guardan en una base de datos local. Al abrir el programa se crea una copia automática por día.

«Crear copia» guarda una copia adicional y descarga un archivo ZIP con la base de datos y ambos Excel originales. Puedes copiarlo a una memoria USB.

La importación se realiza una sola vez. Volver a abrir el programa no duplica los datos ni reemplaza tus cambios. Los Excel originales permanecen sin modificaciones.

Actualizaciones automáticas

Se buscan al abrir y cada cuatro horas. Las descargas verificadas se instalan al cerrar el programa, con copia de seguridad previa. Tus datos no se suben a GitHub.
